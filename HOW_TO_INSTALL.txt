================================================================
  PulseDeck — How to install on a new computer
================================================================

Hi! There are two ways in. The download needs nothing else; the
Python way is for developers and for the Claude Code helper.

----------------------------------------------------------------
  EASIEST — download PulseDeck.exe (no Python needed)
----------------------------------------------------------------

  1. Open https://github.com/avivultra/pulsedeck-/releases and
     download PulseDeck-<version>-windows.zip from the newest
     release.
  2. Unzip it somewhere it will stay, for example
         C:\Users\<your-name>\Documents\PulseDeck\
     (keep the whole PulseDeck folder: the .exe needs the
     _internal folder next to it).
  3. Double-click PulseDeck.exe.

  Windows may say "Windows protected your PC" — the file is not
  signed with a paid certificate yet. Click "More info", then
  "Run anyway". It asks once.

  - Your settings and history live in %LOCALAPPDATA%\PulseDeck
    (paste that into Explorer's address bar to open it), not in
    the program folder, so a newer version can replace the folder.
  - Start with Windows: right-click the strip → "Start with
    Windows". Click it again to stop.
  - Ask Claude needs your own API key: right-click the strip →
    "Claude & Telegram setup", paste the key, "Save and check".
    Windows keeps it encrypted (Credential Manager), not in a file.
    Spending stops before the monthly cap ($5 unless you change
    "claude" → "monthly_usd" in config.json). For a hard limit,
    create the key in its own Console workspace with a $5 spend
    limit. The same window connects a Telegram bot for spending
    alerts and weekly / monthly summaries.
    (Developers: a .env file in %LOCALAPPDATA%\PulseDeck with
    ANTHROPIC_API_KEY=sk-ant-... works too.)
  - Starting it twice just shows "already running".

  Done — the rest of this file is the Python way.

----------------------------------------------------------------
  STEP 1 — Make sure you have Python
----------------------------------------------------------------

Open Command Prompt and type:

    python --version

If you see something like "Python 3.13.0" — you're good, skip to STEP 2.

If you see "command not found" or similar, install Python:
  1. Go to https://www.python.org/downloads/
  2. Click the big yellow "Download Python" button
  3. Run the installer
  4. ** IMPORTANT ** Check the box "Add Python to PATH" on the first screen
  5. Click "Install Now"
  6. Once done, close and reopen Command Prompt and verify with
     `python --version`

----------------------------------------------------------------
  STEP 2 — Copy the folder
----------------------------------------------------------------

Copy this entire folder somewhere convenient on your hard drive,
for example:

    C:\Users\<your-name>\Documents\PulseDeck\

(You can also put it on any drive; just keep it somewhere it
won't be deleted.)

----------------------------------------------------------------
  STEP 3 — Run Install.bat
----------------------------------------------------------------

Double-click `Install.bat`.

It will:
  - Find your Python installation
  - Install the required packages automatically (~1-2 minutes
    first time, depending on your internet speed)
  - Create a "PulseDeck" shortcut on your desktop with a custom
    icon (looks like a futuristic dashboard)
  - Optionally launch the monitor right away

That's it!

----------------------------------------------------------------
  STEP 4 — Daily use
----------------------------------------------------------------

After installation:

  - Double-click the "PulseDeck" icon on your desktop to start
    the monitor. It runs in the background.
  - The dock shows CPU/RAM/disk above your taskbar.
  - The tray icon (by the clock) gives quick access.
  - Right-click on the dock for the full menu:
      • What's happening: a graph of everything on the computer (drag the bubbles, F11 = full screen)
      • View alerts and load detection
      • Clean unnecessary processes
      • Resize, move, pin, font size, etc.

To start automatically when you log in: right-click the strip →
"Start with Windows". Click it again to stop. (You can also turn it
off in Task Manager → Startup apps.)

----------------------------------------------------------------
  Troubleshooting
----------------------------------------------------------------

> "Python is not recognised..."
  You didn't tick "Add Python to PATH" during install. Either:
    a) Reinstall Python with that box ticked, OR
    b) Edit Install.bat — replace `python` with the full path
       like "C:\Users\you\AppData\Local\Programs\Python\Python313\python.exe"

> "pip install failed"
  Check your internet connection and run Install.bat again.

> Dock doesn't appear
  - Make sure the monitor is running (check Task Manager for
    `pythonw.exe`, or `PulseDeck.exe` for the download)
  - Right-click any visible PulseDeck UI element → "Reset position"
  - If you only see the tray icon, that's also fine — the monitor
    is running and writing data.

> Want to uninstall?
  - If you turned on "Start with Windows", turn it off first
    (right-click the strip) — it is the only registry entry
    PulseDeck ever writes.
  - Delete the desktop shortcut "PulseDeck"
  - Delete the folder (the one Install.bat or PulseDeck.exe
    lives in). The .exe also kept its settings and history in
    %LOCALAPPDATA%\PulseDeck — delete that folder too.
  - That's it. No installed services.
